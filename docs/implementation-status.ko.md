## 성능·접근성

로컬 production 빌드의 Lighthouse 13.5 모바일 시뮬레이션 결과다. 실제 사용자 필드 데이터가 아니며 실행 환경에 따라 변동한다. 상세 수치는 [성능 기록](../tests/performance-report.json)에 보존했다.

| 화면          | 성능 | 접근성 |    LCP | CLS |
| ------------- | ---: | -----: | -----: | --: |
| 홈            |   98 |    100 | 2.47초 |   0 |
| Klever 상세   |   93 |    100 | 3.16초 |   0 |
| 프로젝트 목록 |   94 |    100 | 3.01초 |   0 |

세 화면 모두 성능 90 목표를 넘고 자동 접근성 실패 항목이 없다. 상세·목록의 LCP는 2.5초 목표에 아직 미달하므로 운영 CDN에서의 실제 사용자 수치로 추가 관찰해야 한다. 한국어 폰트는 기존 다수의 분할 파일 대신 현재 콘텐츠의 526개 한글을 포함하는 85KB 자체 호스팅 파일로 최적화했다.

## 공개 상태

Vercel 프로젝트는 `jude-parks-projects/hey-joo-portfolio`다. `hey-joo-portfolio.vercel.app`은 검수용 별도 주소이며 `PORTFOLIO_PREVIEW=1`로 검색 색인을 막는다. Vercel 내부에서는 이 고정 별칭을 production target으로 관리하지만, 기존 운영 도메인의 전환을 뜻하지 않는다.

`api.metadata.co.kr`은 아직 GitHub Pages를 가리킨다. DNS는 Cafe24에서 관리되며 기존 CNAME은 `dusskapark.github.io.`다. 도메인 전환 절차와 원복 값은 [운영 문서](deployment-runbook.md)를 따른다.

## 검증 범위의 한계

모든 긴 글의 모든 화면을 픽셀 단위로 수동 비교한 것은 아니다. 전체 콘텐츠·자산은 자동 대조했고 모바일은 모든 문서의 대표 구간, 데스크톱은 공통 화면과 복잡한 사례를 직접 확인했다. 외부 서비스의 과거 영상·SlideShare 재생 가능성 전체, Firefox, 전체 화면낭독기 검수는 확인되지 않았다. 임베드 실패 시 원문 링크는 계속 제공된다.

운영 도메인 전환 후 실제 사용자 성능과 오류에 대한 14일 관찰은 아직 시작하지 않았다.
